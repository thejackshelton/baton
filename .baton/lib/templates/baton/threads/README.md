# Threads

One file per piece of work, named `YYYY-MM-DD-<slug>.md`, committed on the
work's branch as soon as there is something to describe, and kept current
until the PR lands. That way someone on another account can pick the work
up mid-task. Keep it short:

```md
# <What was done>

- **Changed:** what landed and where
- **Left:** what is unfinished or known broken
- **Next agent should know:** anything not obvious from the diff
```
